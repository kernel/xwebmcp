# github.com

| tool | description |
|------|-------------|
| get_file | Reads a file's text or a directory's entries in a public repository at a branch, tag or commit. |
| get_issue | Reads one public issue's title, state, labels, assignees, linked pull requests, body and the timeline items the page holds. |
| get_pull_request | Reads one pull request's state, branches, commits, times, labels and description as text. |
| get_repository | Reads a repository overview: description, topics, counts, license, default branch, latest commit, root entries and README text. |
| get_star_status | Reports whether the signed-in account has starred a repository. |
| prepare_issue | Checks a public repository accepts issues and returns GitHub's new-issue form URL with the title and body filled in. |
| prepare_pull_request | Checks a public repository and returns its comparison page URL for two branches with the pull request title and body filled in. |
| search | Searches repositories, issues or pull requests with GitHub qualifiers and returns one page of 10 results. |
| set_star | Stars or unstars a repository for the signed-in account with one click on its page, then confirms the new state. |
