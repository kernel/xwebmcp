# ubereats.com

| tool | description |
|------|-------------|
| add_to_cart | Adds an item to the signed-in account's cart for its store after validating it against the live menu and its option groups. |
| complete_registration | Continues a sign-up started by register by submitting the one-time code once, then the phone, name and terms screens. |
| get_cart | Reads the signed-in account's carts, one per store, with priced lines, subtotal and total. |
| get_item | Reads one menu item's price, whether it can be ordered now, and its option groups. |
| get_store | Reads one store's details, categories and menu items, or searches its products. |
| login | Signs in to Uber Eats with an email address, one step and at most one submission per call. |
| register | Starts a new Uber Eats account for an email address from a signed-out browser and returns the email-code challenge. |
| resume_registration | Reports where a sign-up in this tab stands and continues past non-code screens without submitting a code. |
| search | Searches stores and products near the session's delivery address, one page per call. |
| update_cart_item | Sets the quantity of one cart line, or removes it with 0. |
