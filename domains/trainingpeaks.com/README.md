# trainingpeaks.com

| tool | description |
|------|-------------|
| add_availability | Adds one Availability entry (days unable to train, or with limited availability) to the signed-in athlete's calendar and confirms it by reading it back. |
| delete_availability | Deletes one Availability entry by id after checking its start date, and confirms it is gone. |
| get_page_context | Describes the open TrainingPeaks page: page type, signed-in account, calendar range, open forms, live tools, loading state and next steps. |
| list_availability | Lists the signed-in athlete's Availability entries (days off) overlapping a date range of up to 365 days. |
| login | Signs in with username and password, submitting at most once, and confirms the signed-in account; an existing session is confirmed without submitting. |
| navigate_to_page | Schedules navigation to a TrainingPeaks app page (Home, Calendar, Dashboard, ATP, Settings, an Availability entry) and carries the app's site map. |
