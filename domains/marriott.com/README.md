# marriott.com

| tool | description |
|------|-------------|
| get_hotel | Reads the public facts of one Marriott hotel from its overview page: address, phone, check-in and check-out times, amenities and its FAQ answers. |
| prepare_reservation | Prepare an unsaved Marriott stay itinerary and manual reservation handoff for an exact property_id and hotel_url from search_hotels, dates, rooms and adults per room. |
| search_hotels | Search Marriott hotels near a destination for a stay: name, brand, distance, rating, review count, and the lowest displayed cash rate per night (or points per room for the stay when use_points is true). |
