# bluebottlecoffee.com

| tool | description |
|------|-------------|
| add_to_cart | Selects One time order, adds the product currently open, and confirms the resulting cart line and cart count. |
| continue_to_checkout | Opens the cart and schedules Continue to Checkout without entering details or submitting an order. |
| get_cart | Opens and reads the current cart, including lines and estimated total, without changing it. |
| get_product | Reads the product currently open, including SKU, price, availability, variants, and supported quantities. |
