# stubhub.com

| tool | description |
|------|-------------|
| get_ticket_offers | Read public StubHub event details and the first ten ticket listings for quantity (default 2, 1–12) using a canonical event URL from search_events. |
| prepare_ticket_choice | Recheck an exact StubHub ticket choice without selecting it: consumes event URL, listing_id, quantity, expected_price_per_ticket and currency from get_ticket_offers. |
| search_events | Search StubHub (US site) for live events by keyword, using the same search results page the site's search box opens. |
