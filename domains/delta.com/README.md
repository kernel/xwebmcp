# delta.com

| tool | description |
|------|-------------|
| continue_to_review_and_pay | On Trip Summary, presses Continue to Review & Pay to move the cart to the Review and Pay page; enters no data and purchases nothing. |
| get_page_context | Describes the current Delta page: its type, the tools it exposes, whether it is still loading, signed-in state, alerts and suggested next steps. |
| get_trip_summary | Reads the Delta cart on Trip Summary or Review and Pay: flight slices, passengers, price breakdown, amount due and refundability. |
| list_flight_results | Lists the itineraries already shown on a Delta results page with every fare column, without searching again. |
| login | Signs in from the Delta homepage by filling the Log in flyout and scheduling one click on its Log In button. |
| navigate_to_page | Navigates the tab to a page on www.delta.com; the description includes a basic site map. |
| search_flights | Searches Delta cash fares for 1–9 adults and returns every first-page outbound option with the lowest displayed fare per row. |
| select_fare | Clicks one fare column on a results itinerary and returns the experiences Delta offers in the drawer it opens. |
| select_fare_experience | Picks one experience in the open fare drawer and selects it, which takes the browser to Trip Summary or to the return results. |
