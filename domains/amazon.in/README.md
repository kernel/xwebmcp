# amazon.in

| tool | description |
|------|-------------|
| add_to_cart | Add exactly ONE unit of an Amazon India guest-cart recommendation, using its dedicated add-to-cart form. |
| get_cart | Read the current Amazon India guest cart and up to 12 public cart recommendations. |
| get_product | Read one Amazon India (amazon.in) product page by asin (the product id returned by search_products and list_bestsellers) and return its public details: title, brand, price and M.R.P. |
| list_bestsellers | Read an Amazon India (amazon.in) Best Sellers chart and return its ranked products, plus the category's subcategories so you can drill down. |
| search_products | Search the Amazon India (amazon.in) catalog by keyword and return one page of results in the site's own order, with the sort, department, price and filter controls the site's results page offers. |
