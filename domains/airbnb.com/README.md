# airbnb.com

| tool | description |
|------|-------------|
| get_listing | Read one public Airbnb listing by numeric listing id or www.airbnb.com/rooms/<id> URL. |
| prepare_booking | Read a preliminary Airbnb booking preview on an already-loaded public listing page with exact dates and adult guests. |
| search_stays | Read the first public Airbnb stays search page for a destination slug, optional dates and adults. |
