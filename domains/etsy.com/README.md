# etsy.com

| tool | description |
|------|-------------|
| add_to_cart | Adds one Etsy listing to the session's cart with the exact variations and personalization the seller requires, and confirms the new cart line. |
| get_cart | Reads the session's Etsy cart (signed in or guest): every line with its line_id, quantity, price, options and personalization, plus totals. |
| get_favorite_status | Checks whether given listings are in the signed-in account's Etsy Favorites. |
| get_listing | Reads one Etsy listing: price, availability, description, images, quantity limit, and every required variation and personalization field. |
| search | Searches Etsy and returns one results page of listings with prices, discounts, shop, rating, badges and ad flags. |
| set_favorite | Adds or removes one listing from the signed-in account's Favorites by pressing its favorite button on the current page. |
| update_cart_item | Sets the quantity of one Etsy cart line, or removes it with 0, and confirms by reading the cart. |
