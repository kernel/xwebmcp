# ebay.com

| tool | description |
|------|-------------|
| get_listing | Reads one eBay listing by item number: price and buying format, condition, availability, shipping, returns, item specifics, the seller and variation menus. |
| get_seller_profile | Reads an eBay seller's public feedback profile by username: score, positive percentage, feedback counts and detailed seller ratings. |
| search | Searches eBay listings with eBay's own sort and filters and returns one results page with price, format, condition, shipping and seller. |
