# ticketmaster.com

| tool | description |
|------|-------------|
| get_event | Reads one event's details: local date and time, venue, performers, on-sale and presale windows, ticket limit and change status. |
| get_ticket_offers | Opens an event page and lists the ticket offers for a quantity with All In per-ticket prices; never selects or holds tickets. |
| search_events | Searches US Ticketmaster events by keyword, city or ZIP, and local date range. |
