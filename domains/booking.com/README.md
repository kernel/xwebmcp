# booking.com

| tool | description |
|------|-------------|
| get_checkout_step | Reads Booking.com's checkout page: the step, property, dates, selected rooms and the total including taxes and fees. |
| get_property | Reads one property's dated room rates with IDs, cancellation, prepayment, meals and excluded fees, plus its address, reviews and check-in and check-out times. |
| search_stays | Searches stays for a destination, dates and party in the site's current currency and returns the first results page with prices and reviews. |
| select_room | Selects one room of an exact rate on the open property page and presses "I'll reserve", which opens Booking.com's details step without booking. |
