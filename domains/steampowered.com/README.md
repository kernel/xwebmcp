# steampowered.com

| tool | description |
|------|-------------|
| get_app | Reads a Steam Store app page, the open one or up to 5 apps by id from any store page: credits, user tags, purchase options with shown prices and discounts, and the review summaries including the all-languages total. |
| get_search_results | Reads Steam Store search results, the open search page or a term's results from any store page: rows with ids, prices, review summaries and the applied sort and filters. Says when more results follow and how to load them, without loading them itself. |
