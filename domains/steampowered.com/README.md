# steampowered.com

| tool | description |
|------|-------------|
| get_app | Reads the open Steam Store app page: purchase options with shown prices and discounts, and the review summaries. |
| get_search_results | Reads the rendered rows of the open Steam Store search results page, with prices, review summaries and the applied sort and filters. |
| search_store | Types a term into the store's header search box and submits it; the tab navigates to the results. |
