# steampowered.com

| tool | description |
|------|-------------|
| get_app | Reads a Steam Store app page, the open one or any app by id from any store page: purchase options with shown prices and discounts, and the review summaries. |
| get_search_results | Reads Steam Store search results, the open search page or a term's results from any store page: rows with prices, review summaries and the applied sort and filters. |
| search_store | Types a term into the store's header search box and submits it; the tab navigates to the results. |
