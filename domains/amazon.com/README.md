# amazon.com

| tool | description |
|------|-------------|
| add_to_cart | Adds one child ASIN that is not yet in the retail cart, after checking get_product's price and seller, and verifies exactly that line appeared; never buys. |
| get_best_sellers | Lists Best Sellers departments, or one page of a department or category ranking. |
| get_cart | Reads the retail cart's lines, quantities, prices and subtotal, plus the session and cart version that cart writes require. |
| get_product | Reads one product's price, availability, rating, seller, delivery wording and child variations. |
| search_products | Searches one results page with the site's sorts, price bounds and filters. |
| update_cart_item | Sets one retail cart line to an absolute quantity, or removes it with 0, and verifies only that line changed. |
