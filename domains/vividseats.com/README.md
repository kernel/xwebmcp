# vividseats.com

| tool | description |
|------|-------------|
| get_event | Read public event details by the exact event URL from search_events: stated local date/time, time zone, lineup, venue address/coordinates and seat restrictions. |
| get_venue | Read the exact public venue URL from get_event: address, time zone, coordinates and capacity if the site supplies it. |
| list_listings | Read the listings an event page shows, in page order: listing id, section, row, ticket count, price per ticket and deal score, plus the page's quantity, price, zone, perks and sort settings. |
| prepare_ticket_selection | Prepare an exact ticket choice without selecting it on the site or creating a hold. |
| search_events | Search Vivid Seats (US marketplace, USD) for events by text, place, dates, category, performer, venue or a lowest-price ceiling, using the same JSON search the site's Explore and results pages call. |
| set_listing_filters | Set the event page's zone, price range, deal score and perks filters through its own controls, or presses Clear. |
| set_listing_sort | Choose lowest or highest price, deal score, row or section order in the event page's sort menu. |
| set_ticket_quantity | Choose how many tickets the event page lists, through its 'How many tickets?' prompt or quantity menu. |
| show_more_listings | Scroll the event page's listings panel to its end once so the page loads its next rows. |
