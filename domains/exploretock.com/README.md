# exploretock.com

| tool | description |
|------|-------------|
| get_availability | Opens one Tock offering's page and lists the slots it shows for a date and party size, with Book or Notify, seating areas, pricing and the calendar's available dates. |
| get_restaurant | Reads one Tock venue's profile: cuisine, address, hours and policies, and its offerings with offering_id, party sizes, seating areas and pricing. |
| prepare_reservation | Prepare an exact table-reservation handoff from an already loaded Tock offering page. |
| search_events | Search Tock ticketed events in one Tock city over an inclusive date range of at most 31 days. |
| search_restaurants | Search Tock (exploretock.com) dine-in restaurants or wineries in one city for a date, party size and time, using the same server-rendered search results page the site's own search form opens (/city/<city>/search). |
