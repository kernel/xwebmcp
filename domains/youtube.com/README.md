# youtube.com

| tool | description |
|------|-------------|
| get_channel | Reads a public channel's profile by channel id: title, description, subscriber and video count text and its tabs. |
| get_playlist | Reads one page of a public or unlisted playlist's videos in site order, with a token for the next page. |
| get_transcript | Reads a slice of the transcript a person already opened on the current paused watch page. |
| get_video | Reads one video's or Short's public metadata: title, description, uploader, publish date, duration, counts and chapters. |
| list_channel_videos | Lists one page of a public channel's Videos or Shorts tab, with a token for the next page. |
| search | Searches YouTube and returns one page of typed video, Short, channel and playlist results with the site's filters. |
| subscribe_channel | Subscribes the expected signed-in account to the channel page that is open, with one click, and reports the observed state. |
