# fandango.com

| tool | description |
|------|-------------|
| get_movie | Reads one movie's synopsis, runtime, rating, directors, cast and scores from its overview page. |
| get_movie_showtimes | Lists one movie's showtimes at the theaters near a required ZIP on one date, with venue-local times and formats. |
| get_theater_showtimes | Lists the movies and showtimes at one theater on one date. |
| get_ticket_offers | Reads the noninteractive reserved-seat preview of one exact screening: areas, ticket types, prices and fees in cents, and seat statuses; never holds a seat. |
| list_movies | Lists one page of the now-playing or coming-soon catalog. |
| prepare_ticket_plan | Revalidates ticket quantities and optional proposed seats for one screening and returns a preview subtotal as a plan only; no cart, hold or checkout. |
| search | Reads the header search suggestions for a query as movie and theater ids with canonical URLs. |
| search_theaters | Lists the theaters near a ZIP or a city and state. |
